# dconf keys that are machine security policy rather than personal preference.
#
# One key per line, as <section>/<key>. Blank lines and # comments are ignored.
#
# These are neither captured by replicate_from_local.sh nor replayed by
# apply_to_local.sh. The source machine runs with "blank screen: never"
# (idle-delay=0), which is also what drives GNOME's automatic lock, and with
# suspend disabled on AC. Replaying that onto every machine provisioned from
# this repository would leave each of them unlocked when left unattended,
# whatever policy the machine had before.
